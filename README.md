# PDS → Excel Summary Tool (오프라인 PDF 데이터시트 → Excel 요약)

플랜트 장비(압력용기, 열교환기, 감온기, 필터 등) Process Data Sheet PDF를 업로드하면 브라우저 안에서 텍스트를 추출·분류·파싱하여, 가독성 높은 Excel 요약 파일로 내보내는 **완전 오프라인/독립 실행** 웹 도구입니다. 서버나 인터넷 연결 없이 동작하며, 업로드한 PDF 내용은 어디로도 전송되지 않습니다 (모든 처리가 브라우저 로컬에서 실행).

## 사용법

1. `index.html`을 더블클릭(또는 브라우저에 드래그)해서 엽니다. (인터넷 연결은 pdf.js/ExcelJS 라이브러리를 CDN에서 불러오는 첫 로딩 시에만 필요하고, 이후 파일 처리 자체는 오프라인으로 동작합니다.)
2. **1. 업로드 & 추출** 탭에서 PDF 파일을 드래그하거나 선택합니다. 여러 개를 한 번에 넣을 수 있습니다.
3. 자동으로 텍스트 추출 → 장비종류 분류(Vessel/열교환기/감온기/필터) → 표준 항목 매칭이 진행됩니다.
4. **2. 검토 & 수정** 탭에서 각 파일별로 인식된 값을 확인하고 직접 수정할 수 있습니다. 사전에 없는 라벨은 "기타 항목"에 원문 그대로 모여 체크박스로 포함 여부를 고를 수 있습니다.
5. **3. 내보내기 설정** 탭에서 시트 구성 방식(통합 vs 분리)과 포함할 항목을 고른 뒤 "Excel로 내보내기"를 누르면 `.xlsx` 파일이 다운로드됩니다.
6. **4. 필드 사전** 탭에서 회사/벤더별로 다르게 쓰는 라벨 표현(동의어)을 추가하면, 다음부터 그 표현도 자동 인식됩니다. (브라우저 로컬 저장소에 저장되어 다음에 열어도 유지됩니다.)

## 내보내기 모드

- **통합(Consolidated)**: 장비 여러 개를 표 1개(행=장비, 열=항목)로 비교. 장비군끼리 항목이 다르면 빈 칸(—)으로 표시됩니다.
- **분리(Separate Sheets)**: 장비마다 시트를 따로 만들어 원본 데이터시트처럼 라벨-값 형태로 정리. "기타 항목" 섹션도 포함 가능합니다.

## 지원 장비 유형 (자동 분류 대상)

Vessel/Column(압력용기), Heat Exchanger(열교환기, Shell&Tube 등), Desuperheater(감온기), Filter(필터) — 키워드 기반 스코어링으로 자동 판별하며, 검토 탭에서 수동으로 바꿀 수 있습니다. 위 4종에 해당하지 않는 문서는 "미분류(Unknown)"로 표시되고 표준 항목 없이 "기타" 항목 위주로 추출됩니다.

## 동작 원리 (요약)

1. **pdf.js**로 PDF의 텍스트 레이어를 위치정보(x, y좌표)와 함께 추출합니다.
2. 같은 y좌표(줄)끼리 묶고, x 간격이 일정 이상 벌어지면 별도 "컬럼"(라벨/값 셀 구분)으로 재구성합니다. 표 형태든, "라벨: 값" 형태든, "라벨    값"(공백 여러 칸) 형태든 시도합니다.
3. 각 줄의 라벨 후보를 **필드 사전**(표준필드 56개 + 각 필드별 한/영 동의어 목록)과 대조해 가장 잘 맞는 표준 필드에 매칭합니다.
4. 문서 전체 텍스트를 키워드 스코어링으로 장비종류를 추정하고, 동점 매칭 시 해당 장비군 필드를 우선합니다.
5. 매칭 안 된 라벨:값 쌍은 버리지 않고 "기타" 항목으로 보존합니다(손실 없는 폴백).
6. **ExcelJS**로 헤더 색상/테두리/틀고정/자동필터 등을 적용한 서식 있는 `.xlsx`를 생성합니다.

## ⚠ 알려진 한계 (반드시 확인)

- **오프라인 패턴(regex) 기반 파싱**이므로, 벤더/회사마다 다른 PDF 양식·표 구조에서는 항목을 못 찾거나(누락) 다른 항목에 잘못 매칭(오탐)될 수 있습니다. **내보내기 전 반드시 "검토 & 수정" 탭에서 값을 확인하세요.**
- **스캔본(이미지) PDF는 텍스트 레이어가 없어 자동 인식이 불가능**합니다. 업로드 시 "⚠ 텍스트 레이어 없음" 경고가 표시되며, 이 경우 항목을 수동으로 입력해야 합니다. (OCR 기능은 포함되어 있지 않습니다.)
- 표가 복잡하게 병합되어 있거나, 라벨과 값이 시각적으로 멀리 떨어진 레이아웃, 다단(2단/3단) 레이아웃에서는 컬럼 재구성이 부정확할 수 있습니다.
- 동일 문서에 같은 항목이 여러 번 나오면(예: 여러 노즐의 개별 사양) 첫 번째 값만 대표로 채택하고 나머지는 내부적으로 "대안값"으로만 기록됩니다(현재 UI에는 미표시 — 필요 시 알려주시면 검토탭에 노출하도록 추가하겠습니다).
- 필드 사전에 없는 완전히 새로운 항목 표현은 "기타"로만 잡히므로, 반복적으로 나오는 회사 양식이라면 **필드 사전 탭에서 동의어를 추가**해 인식률을 높이는 것을 권장합니다.

## 파일 구성

```
pds-to-excel/
├── index.html              (UI 골격 — 4개 탭)
├── style.css                (스타일)
├── js/
│   ├── field-dictionary.js  (표준 필드 56개 + 동의어 사전, 커스텀 동의어 localStorage 저장)
│   ├── classify.js          (장비종류 자동 분류 — 키워드 스코어링)
│   ├── pdf-extract.js       (pdf.js 래퍼 — 좌표기반 줄/컬럼 재구성)
│   ├── parse-fields.js      (라벨:값 매칭 엔진 — 사전 대조 + 장비종류 힌트로 동점 해소)
│   ├── excel-export.js      (ExcelJS 기반 통합/분리 시트 생성)
│   └── app.js                (업로드~검토~내보내기~사전관리 UI 연동)
└── README.md
```

## 검증 내역

- 6개 JS 모듈 전체 `node --check` 문법 검증 통과.
- Node 환경에서 브라우저 전역(window/localStorage/document)을 최소 스텁으로 대체해 핵심 로직(필드사전 조회/동의어 추가·삭제, 장비종류 분류, 합성 PDF 텍스트에 대한 라벨:값 매칭) 단위 테스트 수행 — 아래 항목 확인:
  - 압력용기/열교환기/필터 텍스트에 대한 장비종류 자동 분류 정상 동작
  - "라벨: 값", "라벨   값"(공백구분), 표(컬럼) 형태 모두 정상 매칭
  - 음수 값(MDMT -29°C 등)이 값 정리(clean) 과정에서 손실되지 않도록 수정·검증
  - 서로 다른 장비군에 같은 동의어가 걸리는 경우(예: "Flow Rate") 장비종류 힌트로 올바른 필드에 매칭되도록 검증
  - 매칭 실패 항목이 "기타" 버킷에 손실 없이 보존되는지 검증
- ExcelJS/pdf.js는 브라우저 전용 CDN 로드 라이브러리이므로 이 환경(Node, 외부 네트워크 제한)에서는 실제 `.xlsx` 바이트 생성까지는 검증하지 못했습니다 — **직접 브라우저에서 열어 실제 PDF로 한 번 테스트해 보시고, 이상 있으면 알려주세요.**
